# eve/

This folder is **EVE itself**: the Event Book, its tools, the rules your AI follows (`AGENTS.md`), the sample app and the template's website. Your app, plan and design live at the top level, outside this folder.

Don't edit anything here. To get a newer EVE, tell your AI **update EVE** (or run `node eve/update.mjs`): it replaces this folder and the `eve-*` skills, and nothing else.

More: https://github.com/jocelynenglund/itsybit-eve-template

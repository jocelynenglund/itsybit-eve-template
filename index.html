How it goes

  1. 01
    let's plan a storage-box trackerThe AI writes the plan and opens the Event Book. Comment on anything, add the examples you're missing, tick Refined when a slice is right, then press Done with feedback.
  2. 02
    done with feedbackEvery comment answered, the next round served. Repeat until every slice is refined.
  3. 03
    start buildingEach slice built test-first; the book turns green as the tests pass. Then open the app in your browser.
  4. 04
    make it beautifulYour plan becomes a design brief for your design tool, and the app gets the look you pick. Every test still has to pass.
  5. 05
    update EVENewer tools from this template. Your plan and your app are never touched.

The Event Book

COMMANDAddBox→BoxAdded
BUILT✓ Refined
Adds a box
GIVENnothingWHENAddBoxTHENBoxAdded
Refuses a name another box already has
GIVENBoxAddedWHENAddBoxTHENrefused: “You already have a box with that name”

Every thing your app can do is a slice, with Given / When / Then examples you agree on before any code. Each example becomes a test; the dot turns green when it passes.

Start

On GitHub, press Use this template to make your own copy (it can be private). Then:

git clone https://github.com/you/my-app
cd my-app
claude            # or Cursor, Codex, any assistant that reads AGENTS.md
> let's plan a todo app

You need Node 18 or newer; there's nothing to install. When EVE gets better, your Event Book says so: tell your AI update EVE.

A real session

A storage-box tracker, built in an afternoon. These are the messages the person typed, word for word:

  1. YOUlet's plan an app to track my boxes that i put into storage. I basically want to be able to make a qr code for my boxes that are linked to a list of things that are in it. so it makes knowing what's in the boxes easier.

    The AI writes the plan and opens the Event Book. They comment, add scenarios, tick Refined, and press Done with feedback.

  2. YOUdone with feedback

    Every comment answered, the next round served. Repeat until every slice is refined.

  3. YOUstart building

    Each slice built test-first; the book turns green as the tests pass. The app opens in the browser.

  4. YOUI want to add a feature that shows me a view of which boxes i have taken things out of most often so i can maybe reorganize better.

    New slices join the plan. The built ones fold away in the book so the new ones stand out. Refine, then build again.

  5. YOUmake it beautiful

    The plan becomes a design brief for their design tool, and the app gets the new look. Every test still passes.
